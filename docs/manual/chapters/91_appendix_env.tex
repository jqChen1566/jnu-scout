\begin{notebox}[On the NNP\_AFIR\_* prefix]
The \code{NNP_AFIR_*} names are kept from earlier deployments for
compatibility; environment variables introduced later use the
\code{JNUSCOUT_*} prefix.  Treat both prefixes as part of the stable
interface: renamed variables would silently disable patches on machines
that have the old names exported.
\end{notebox}

\begin{readbox}[Offline machines]
On machines without network access, set \code{MACE_MP0_PATH} and
\code{MACE_MPA0_PATH} to local \code{.model} files before the first
calculation; otherwise MACE attempts to download its weights when the
committee is constructed.  ORCA and xtb are external executables and are
never downloaded by this package.
\end{readbox}
